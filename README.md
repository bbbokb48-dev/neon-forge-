## Comment visualiser

1. Télécharge le dossier `neonforge`
2. Ouvre `index.html` dans ton navigateur (double-clic)
3. Navigue entre les pages normalement

Aucun serveur ni installation nécessaire.

## Produits inclus

39 produits réels (claviers, souris, casques, chaises, setup & déco) avec images.

## Personnalisation rapide

- Changer le nom de la marque → cherche `NeonForge` dans tous les fichiers
- Ajouter / modifier des produits → édite le tableau `products` dans `js/products.js`
- Couleurs → variables CSS en haut de `css/style.css`
